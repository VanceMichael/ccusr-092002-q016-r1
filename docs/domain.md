# 领域资料

渔民共同出资的科考船首次海试时，需在实际海况中同时验证走航采样仪、冷藏样本舱与定位设备的协同工作。船厂在港口完成的单机合格记录不能替代海上协同验证，因此建立**科研载荷海试验收服务**，按试航科目关联装船仪器、校准证书、样本交接、海上观测时间与可复现实验记录。

## 边界与不变量

- **航次是验收边界**：每个科目属于唯一航次；仪器的校准证书、海上观测时间窗、实验记录均按航次登记。科目的合格判定（`app.service.evaluate_subject`）只统计本航次证据，其他航次的"通过"结论不计入，杜绝冒用。
- **航段挂接校验**：观测窗与实验必须挂在本科目航次内的航段上，跨航次挂接返回 422。
- **证书时效**：校准证书按航次签发，结论须为"合格"，且在开航前仍在有效期内。
- **原始读数不可变**：读数只追加，系统不提供修改或删除接口；异常数据保留 `raw_value` 原始读数，且必须登记复核人 `reviewed_by` 与复核结论（确认异常/误报修正）后，科目才能标记为已完成。复核记录登记后不可更改。
- **可复现实验**：每条实验记录保存规程版本 `protocol_ref` 与参数 JSON 快照 `parameters`。
- **样本可追溯**：样本登记来源科目、实验、采集人与采集时间，交接链只追加（`sample_handovers.seq`）。
- **授权范围**：研究机构只能追溯被授权（单样本或整科目）的样本来源，不能冒充其他机构查询。

## 角色

| 角色 | 令牌 role | 能做什么 |
| --- | --- | --- |
| 海洋科研团队 | `scientist` | 录入航次/航段/仪器/证书/科目/观测/实验/读数/样本/交接，发放样本授权，复核异常读数 |
| 靠港验收人员 | `acceptance` | 判定科目完成或判退、登记仪器逐航次验收结论、查看完整验收报告 |
| 船东 | `owner` | 只查看每台设备是否满足交付条件（`/voyages/{id}/delivery`），看不到证据明细与人员 |
| 研究机构 | `researcher` | 在授权范围内追溯样本来源与交接链（`/samples/trace`） |

`contracts/entities.json` 保存交换字段与判定规则；`fixtures/example.json` 为不含真实个人资料的虚构示例。运行时持久化文件由 `DATABASE_PATH` 决定；时间字段一律使用带时区偏移的 ISO 8601 字符串。
