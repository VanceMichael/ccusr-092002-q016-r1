# 领域资料

科研载荷海试验收围绕**航次（voyage）**组织：走航采样仪、冷藏样本舱、定位设备必须在同一航次的实际海况中，通过试航科目关联装船仪器、校准证书、海上观测时间与可复现实验记录完成协同验证。船厂在港口的单机合格记录（`yard_record_ref`）只作为来源材料登记，不能替代海试结论。

## 航次隔离

观测窗口必须引用**本航次航段**：向科目挂接他航次航段返回 409。科目结论的合格证据（观测窗口、实验记录、读数、校准覆盖）全部按 `subjects.voyage_id` 归属计算。因此一个科目未完成时，系统无法用另一航次的合格结论顶替。

## 异常数据留痕

`readings.raw_value` 为只增不改的原始读数列（服务层不提供任何更新原始值的操作，复核接口 `PUT/POST /readings/{id}/review` 只写复核字段）。异常读数允许海上先标记（`anomaly=1`、复核人为空），靠港后由验收人员补登复核人与说明；存在未复核异常读数时科目判合格会被阻断（422）。

## 判定规则（PASSED 前置条件）

- 科目关联至少一件本船仪器（他船仪器关联返回 409）；
- 至少一个本航次观测窗口；
- 至少一次可复现实验记录（程序编号 + 参数 JSON + 操作人 + 时间）；
- 至少一条读数；
- 全部异常读数已有复核人；
- 每件关联仪器的校准证书有效期覆盖每个观测窗口。

不满足时只能判 `RETEST_REQUIRED` 且必须填写复测原因。判定由验收人员（inspector）作出，记录 `decided_by/decided_at`。

## 角色与视图

| 角色 | 能力 |
| --- | --- |
| `coordinator` 科研负责人团队 | 航次/航段/科目/仪器建档与关联、发放样本追溯授权 |
| `inspector` 靠港验收人员 | 校准证书登记、异常复核、科目判定，查看交付与验收明细 |
| `researcher` 研究机构 | 登记观测/实验/读数/样本交接；凭 `X-Actor-Ref` 机构标识在授权范围内追溯样本来源 |
| `shipowner` 船东 | 仅 `GET /voyages/{id}/delivery`：逐仪器是否满足交付条件，不含任何观测数据 |

样本来源追溯（`/samples/{ref}/provenance` 与 `/readings`）仅对研究机构开放，并按 `sample_access_grants` 逐样本、逐机构鉴权；未授权返回 403。

## 数据约定

时间字段使用带时区偏移的 ISO 8601 字符串，服务端归一化为 UTC 存储，因此有效期/窗口的字符串比较与时区无关。运行时持久化文件由 `DATABASE_PATH` 决定；示例文件 `fixtures/example.json` 不含真实身份信息。来源编号仅表示提交方对同一记录的识别符。
